## О проекте

**Analytics** — веб-приложение на Next.js для визуализации личных финансов. Загружайте CSV-выписки банка и HTML-отчёты брокера Сбера, фильтруйте транзакции, смотрите графики расходов и моделируйте рост капитала с учётом налогов, инфляции и долгов.

> Основное хранилище — **IndexedDB в браузере**. При наличии backend-API данные дополнительно синхронизируются в резервную копию на сервере.

## ✨ Возможности

### 💳 Выписка

| Функция | Описание |
|--------|----------|
| **Импорт CSV** | Drag-and-drop или выбор файлов; автоматическое объединение и дедупликация |
| **Фильтры** | По дате, категории, мерчанту, сумме и типу операции |
| **Графики** | Расходы по категориям, дневной денежный поток, топ мерчантов |
| **Таблица** | Полный список транзакций с сортировкой |

### 📈 Инвестиции — сводка

| Функция | Описание |
|--------|----------|
| **Общий капитал** | Брокер + другие активы, прогноз доходности и диверсификация |
| **Ближайшие события** | Закрытие вкладов и последние платежи по кредитам |
| **Сравнение с рынком** | Доходность брокерского счёта vs индексы MOEX (основные и сектора), RGBI и курсы ЦБ; периоды по месяцам, с начала года и за всё время |
| **Диверсификация** | Доля классов активов, HHI по бумагам, топ позиций |

### 📈 Инвестиции — портфель Сбера

| Функция | Описание |
|--------|----------|
| **HTML-отчёт** | Парсинг отчёта брокера: позиции, денежные потоки, аллокация |
| **T+1** | Нерасчитанные покупки учитываются в плановом остатке позиций и кэша |
| **История снимков** | Каждая загрузка сохраняется для динамики и сравнения |
| **Diff отчётов** | Изменения позиций, кэша и пополнений между двумя последними отчётами |

### 📈 Инвестиции — другие активы

| Функция | Описание |
|--------|----------|
| **Классы активов** | Недвижимость, крипто, произвольные активы с доходностью или арендой |
| **Кредиты и долги** | Ежемесячные платежи, ставка, день списания |
| **Срочные вклады** | Фиксированный срок, ставка, дата открытия; расчёт выплаты при закрытии |

### 📈 Сложный процент и сценарии

| Функция | Описание |
|--------|----------|
| **Симуляция** | Взносы, рост, инфляция, налоги, отдельный учёт платежей по долгу |
| **Monte Carlo** | Веер сценариев P10 / P50 / P90 на графике |
| **Сохранённые планы** | Несколько сценариев прогноза; восстановление параметров в калькуляторе |
| **IRR и безопасное снятие** | Фактическая доходность и оценка устойчивого изъятия |

### 📈 Трекинг «план vs факт»

| Функция | Описание |
|--------|----------|
| **Помесячная таблица** | Баланс, пополнения брокера, вклад в долг по сохранённым сценариям |
| **Тело долга (факт)** | Сколько реально погашено по основному долгу (из истории активов и отчётов) |
| **Живой прогноз** | Гибридный forecast от текущих данных: взнос сценария или ручной ввод, горизонт до конца плана |
| **График** | План, факт и live-forecast на одном chart |

### 🎨 Интерфейс

- Тёмная и светлая тема
- Адаптивная вёрстка
- Drag-and-drop загрузка CSV и HTML на соответствующих страницах
- Экспорт / импорт полного бэкапа (выписки + портфель)

## 🚀 Быстрый старт

### Онлайн (Vercel)

Production-сборка публикуется на **Vercel**. Актуальный URL — в [Vercel Dashboard](https://vercel.com/dashboard) у проекта, привязанного к репозиторию `icube1/analytics`.

### Локально

**Требования:** Node.js 20+, npm (или pnpm / yarn / bun)

```bash
git clone https://github.com/icube1/analytics.git
cd analytics
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) — выписка, [http://localhost:3000/investments](http://localhost:3000/investments) — инвестиции.

### Сборка и тесты

```bash
npm run build          # production-сборка
npm run build:standalone  # standalone-бандл для деплоя
npm run start          # production-сервер
npm test               # unit-тесты (Jest)
npm run lint           # ESLint
```

CI на GitHub Actions: тесты и сборка при push в `master`.

## 🔒 Конфиденциальность

- Персональные данные **в первую очередь хранятся в браузере** (IndexedDB) и **не попадают в git**.
- При работе с backend автоматически создаётся **резервная копия** (портфель + выписки) — удобно при смене устройства или очистке кэша.
- Запросы к **MOEX ISS** и **cbr-xml-daily.ru** — только публичные котировки для блока «Сравнение с рынком»; личные данные туда не отправляются.
- Индексы MOEX в сравнении — **изменение цены**, без дивидendов; учитывается только брокерский счёт.

Пример конфигурации портфеля: `data/portfolio.example.json`.

Отслеживаемые HTML-фикстуры брокера обезличиваются скриптом `npm run sanitize:broker-fixtures`. Подробности и **риск остаточных данных в истории git** — в [docs/broker-fixture-sanitization.md](docs/broker-fixture-sanitization.md).
