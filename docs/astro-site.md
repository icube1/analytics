# Astro marketing site

Parallel static marketing and education site in `apps/site/`. Production Next.js (`app/`) and Vite SPA (`apps/web/`) are unchanged — **no production cutover** until explicitly planned in the architecture roadmap.

## Purpose

Russian-language landing focused on:

- financial resilience and layered emergency reserves;
- debt-aware planning and household scenarios;
- immediate feedback when assumptions change;
- long-term independence after reaching chosen reserve ranges;
- privacy-first positioning (no third-party trackers on this site);
- clear CTA to [app.gala-soft.ru](https://app.gala-soft.ru).

The interactive demo on the homepage is an isolated in-browser illustration. It does not call APIs, does not name securities, and does not promise guaranteed outcomes.

## Commands

From repository root:

```bash
npm install
npm run dev:site          # http://localhost:4321
npm run build:site        # astro build → apps/site/dist
npm run typecheck:site
npm run test:site         # build + SEO/size assertions
npm run test:site:a11y    # a11y checks on dist (after build)
```

From `apps/site/`:

```bash
npm run dev
npm run build
npm run preview
npm run test
npm run test:a11y
```

## Design tokens

`src/styles/tokens.css` mirrors the palette from root `app/globals.css` (`--background`, `--foreground`, accent indigo). The site does not import Tailwind or Recharts to keep the dependency footprint small.

## SEO

- Per-page `<title>`, description, canonical, Open Graph, and Twitter card metadata via `BaseLayout.astro`.
- `public/robots.txt` references `sitemap-index.xml` (generated by `@astrojs/sitemap`).
- `site` in `astro.config.mjs` is `https://gala-soft.ru`.

## Deployment (future)

When ready, serve `apps/site/dist` at `gala-soft.ru` via nginx alongside existing routes. Until then, build artifacts stay in CI only.

## Dependency footprint

Runtime npm dependencies: `astro`, `@astrojs/sitemap` only. No React, no analytics SDKs.
